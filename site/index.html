왜 MyBar인가

아이콘은 그대로, 메뉴바는 깔끔하게.

앱을 깔 때마다 메뉴바 아이콘이 하나씩 늘어납니다. 노치가 있는 MacBook에서는 넘치는 아이콘이 노치 뒤로 사라지기도 하죠.
MyBar는 지금 필요한 아이템만 메뉴바에 남기고, 나머지는 한 번의 클릭 거리에 둡니다.

동작 방식

macOS 27의 새 메뉴바에 맞춰.

macOS 27은 메뉴바를 새 시스템 프로세스가 통째로 그립니다. MyBar는 메뉴바의 허용 목록을 써서 숨길 앱을 메뉴바에서 빼고, 누를 때만 잠깐 허용합니다.

  1. 1

    숨기기

    숨길 앱을 뺀 나머지만 메뉴바에 허용합니다. 빈칸도, 접힌 «도 남지 않습니다.

  2. 2

    꺼내기

    바에서 누른 앱만 잠깐 허용하면 아이템이 제자리에 나타나고, MyBar가 대신 눌러 줍니다.

  3. 3

    되돌리기

    메뉴가 닫히고 몇 초 지나면 다시 숨깁니다. MyBar가 종료되면 모든 아이템이 그대로 돌아옵니다.

macOS 26에서는 긴 구분선으로 아이템을 화면 밖으로 밀어내는 방식으로 동작합니다. 자세한 내용은 개발 문서에 있어요.

FAQ

자주 묻는 질문

정말 무료인가요?

네. MIT 라이선스의 오픈소스이고, 광고나 유료 기능이 없습니다.

화면 기록 권한은 왜 필요한가요?

숨긴 아이템을 바에 보여 주려면 메뉴바 아이콘의 그림이 필요하기 때문입니다. 메뉴바 영역만 찍고, 어떤 데이터도 밖으로 보내지 않습니다. 코드는 전부 GitHub에 공개되어 있어요.

왜 App Store에 없나요?

App Store 앱은 샌드박스 안에서만 동작해서 다른 앱의 메뉴바 아이템을 다룰 수 없습니다. 대신 Apple 공증을 받은 DMG로 배포합니다.

macOS 업데이트 후 동작하지 않아요.

macOS 27의 메뉴바 기능 일부는 공개되지 않은 인터페이스라 업데이트로 바뀔 수 있습니다. 이슈에 설정 › Permissions › Copy Diagnostics 결과를 붙여 알려 주세요.

MyBar를 지우면 숨긴 아이템은요?

MyBar를 종료하는 순간 숨긴 아이템이 모두 돌아옵니다. 그다음 휴지통으로 옮기면 됩니다.

한 앱의 아이템 여러 개를 따로 숨길 수 있나요?

macOS 27에서는 앱 단위로만 숨길 수 있습니다. 메뉴바가 앱 단위로 허용 여부를 정하기 때문이에요.
